# Vedyn Apps — Logo Assets

**Primary mark: Grounded Salute** · Backup: The Watcher
Brand amber `#E8A84A` on void `#0D0D10`.

## Files
| File | Use |
|------|-----|
| `vedyn-mark.svg` | Primary mark, amber, transparent — scalable master |
| `vedyn-mark-ink.svg` | Ink `#1A1206` for light / print backgrounds |
| `vedyn-mark-cream.svg` | Cream `#F0EEE8` for photos / dark imagery |
| `vedyn-appicon.svg` | Full iOS/macOS app icon (squircle + glow) |
| `app-icon-1024.png` / `app-icon-512.png` | Store & system app icon |
| `apple-touch-icon.png` | 180×180 web touch icon |
| `favicon-48/32/16.png` | Browser tab favicons |
| `vedyn-watcher.svg` / `vedyn-watcher-appicon.svg` | Backup mark + its app icon |
| `head-snippet.html` | Drop-in `<head>` tags for favicons |

## Rules
- Single flat color only. The glow lives **only** in the app icon, never the flat mark.
- Scale uniformly — never stretch one axis or rotate the figure.
- Clear space ≥ the head's diameter on all sides.
- Palette: Amber `#E8A84A` · Void `#0D0D10` · Ink `#1A1206` · Cream `#F0EEE8`.

Need other sizes (Android adaptive, 192/512 PWA, .ico)? Ask and they'll be generated from the master SVG.
